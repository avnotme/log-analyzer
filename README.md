# Log Analyzer

A Python tool that analyzes SSH authentication logs to detect brute-force login attempts.

Developed by Aamin Vhora, while simultaneously learning how to code in python for future projects.
Check [DEVLOG](DEVLOG.md), to see the progressive development of both this project and my knowledge.


## What it does
- Reads SSH log files in the following formats:
    - RFC 3164


## How to run
Windows:
```
py log-analyzer.py <path-to-log-file>
```

Mac:
```
python3 log-analyzer.py <path-to-log-file>
```
